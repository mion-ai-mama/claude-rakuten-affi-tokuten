# Claude×楽天アフィ 自動化スタートガイド（要件定義）

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論・ビルド不要の静的サイト）
- 操作者: ブラウザのエンドユーザー / AI本体: なし / MCP: なし / 自社DB: なし / フロントUI: あり
- 種別: Web型（GitHub Pages） / 配布: マイ専用

## 1. 目的

リール「商品探して投稿する作業、もうやりたくない」から誘導する無料特典。リール最後の約束「最初の設定とプロンプト」を受け取れるページ。完全自動化の完成ではなく、AI初心者が商品紹介の準備を自分で体験する最初の一歩。

- ターゲット: 40〜50代のAI初心者女性（Claude未経験〜簡単なチャットのみ／プログラミング・API設定はできない）
- 配布導線: リールコメント→DM→オプチャ→特典まとめ。**このページにはアフィリエイトリンクを置かない**（楽天ガイドラインがLINE/オープンチャット等でのアフィリエイトリンク掲載を禁止しているため）

## 2. 構成

ファーストビュー → SEC1 何ができる？（従来 vs AI活用／基本編・発展編の区別）→ SEC2 準備するもの（3カード）→ 基本編 STEP1〜4 → SEC7 発展編（レベル1〜3）→ SEC8 気をつけたいこと → SEC9 LINE誘導＋教科書バナー＋AI収益化サポート会

## 3. デザイン

制作指示書の指定により、v2共通仕様（白×黒×グレージュ）ではなく**アイボリー×ブラウン×ベージュ＋くすみピンク（アクセント）**。値は css/style.css の :root が単一の源。ピンクは発展編・注意ボックス・ラベルのみ。基本編＝ブラウン、発展編＝ピンクの破線枠で一目で区別。

## 4. 公式確認済みの事実（2026-10-19、楽天アフィリエイト公式サイトを実ブラウザで確認）

- ログイン導線:「楽天IDでログイン」「楽天会員に新規登録」（/guides/begin/）。楽天会員登録は無料
- 商品リンク取得: トップ上部「楽天市場の商品を検索」→ 各商品の「商品リンク作成」→「商品リンクを作成」画面の「リンクタイプを選択する」（画像とテキスト／画像のみ／テキストのみ／短縮URL／リンクのみ）。SNSは「短縮URL」または「リンクのみ」
- Threads は認定SNS（ガイドライン）。非公開アカウントは対象外。LINE・オープンチャット・DM等へのリンク掲載は禁止
- 広告表記: 最初に表示される画面内に「広告」「PR」「宣伝」「プロモーション」等（「AD」「sponsored」は不可）。Rakuten公式のステマ規制ページ
- Claude: 無料プランあり。有料は月額20ドル前後〜（claude.com/pricing）
